# 小鹊云管理后台

运营人员使用的官网管理后台：搭建页面、维护导航与站点配置、管理素材、跟进表单留言。

当前初版已接入 Go 后端，页面、导航、站点配置、素材与留言均以服务端数据为准；仅登录页展示设置仍保存在当前浏览器。

## 技术栈

- Vue 3.5 + TypeScript
- Vite 6
- Element Plus
- Pinia
- Vue Router（hash 模式）
- TipTap（富文本）
- vue-draggable-plus（拖拽排序）

## 功能

### 登录与账号

- 账号密码登录，调用 Go 后端 `/api/v1/admin/auth/login`
- 前端图形验证码（可在基础设置关闭）
- 登录会话由后端写入 HttpOnly Cookie `xqyun_admin_session`，前端不保存令牌
- 刷新页面时调用 `GET /admin/me` 校验会话；接口返回 `40100` 时跳回登录页
- 管理员资料、头像、修改密码
- 修改密码后当前会话被删除，需要重新登录

### 站点编排

顶部四个 Tab：

1. **页面内容**
   - 按语言、状态、关键词筛选
   - 新建、复制、删除、预览、发布、下架
   - 中英文翻译配对
2. **顶部导航**
   - 菜单项、显示隐藏、拖拽排序
   - 顶部按钮、公告条、语言入口、滚动吸顶
3. **底部导航**
   - 页脚栏目与链接、联系入口、品牌标语、版权 / ICP、底部链接
4. **站点配置**
   - 官网 Logo、品牌主色、页面底色、深色区块底色
   - 搜索引擎收录开关

### 页面编辑器

- 左栏：区块结构，支持添加、拖拽排序、复制、删除
- 中栏：由区块 schema 自动生成的属性表单
- 右栏：iframe 实时预览，支持桌面 / 平板 / 手机
- 点击区块自动滚动预览到对应位置
- 停止编辑 3 秒自动保存草稿，支持 `Ctrl / Cmd + S` 手动保存
- 撤销 / 重做
- 发布前校验，发布覆盖线上内容
- 草稿和发布会区分语言，中文 / 英文独立发布

### 区块

包含 14 种区块：首屏横幅、头部轮播、富文本、图文组合、特性列表、数据统计、产品列表、新闻列表、客户案例、合作伙伴、常见问题、行动号召、联系表单、视频。

图片字段统一为「内置图形 / 素材库」两种来源；视频字段支持素材库选择或直链；富文本插图会先上传素材库再插入 URL。

### 素材管理

独立一级菜单「资源 → 素材管理」：

- 全部 / 视频 / 图片筛选
- 关键词搜索
- 上传、预览、重命名
- 单个删除、勾选批量删除
- 视频最大 200MB，图片最大 10MB

### 表单留言

独立一级菜单「线索 → 表单留言」：

- 待处理数量红点，超过 99 显示 `99+`
- 状态、语言、关键词筛选
- 留言详情
- 标记处理中 / 已完成 / 垃圾 / 恢复待处理
- 按当前筛选条件导出 CSV

### 基础设置

- 后台登录页验证码开关
- 登录页底图、品牌名称、标题与说明文字
- 仅保存在当前浏览器，不随其他设备同步

## 开发

```bash
npm install
npm run dev        # http://localhost:5174/#/pages
npm run typecheck  # vue-tsc --noEmit
npm run build      # 产物 dist/，包含 admin + preview 两个入口
npm run preview    # 本地预览构建产物
```

开发环境需要 Go 后端，默认代理到 `http://127.0.0.1:8888`。可通过环境变量覆盖：

```bash
VITE_API_PROXY_TARGET=http://127.0.0.1:8888
```

生产构建的 API 前缀默认 `/api/v1`：

```bash
VITE_API_BASE_URL=/api/v1
```

前后端同域部署时保持默认即可；不同域时需要 Go 后端配置 CORS 或反向代理。

## 生产部署

生产构建产物是静态文件，由统一的 Nginx 网关挂在 `/admin/`：

- 官网：`/`
- 管理后台：`/admin/`
- API：`/api/v1/`
- 素材：`/uploads/`

后台不再单独占用一个 Nginx 或独立端口。Docker 部署说明见项目根目录的 [`deploy/docker/xqyun/README.md`](../deploy/docker/xqyun/README.md)。

## 说明

- 管理后台使用 hash 路由，刷新页面不需要服务端路由支持。
- 页面、导航、站点配置、素材、留言来自 Go API；本地只保存登录会话和登录页展示设置。
- 后台与官网各自维护一份区块 schema，调整区块字段时两边都要同步。
- 初始管理员账号为 `admin` / `123456`，首次登录后请立即修改。
- 更多项目说明见根目录 [`README.md`](../README.md)；运营操作见 [`docs/运营人员使用手册.docx`](../docs/运营人员使用手册.docx)。
